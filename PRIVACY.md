# Privacy Policy

OGENIC GOD TOOLKIT processes only the data needed to route or complete a user-requested workflow. The v1.3.0 MCP MVP receives a user-provided request, returns a capability route, and displays capability/runtime/approval status. Optional connected execution surfaces may process repository content, workflow configuration, file metadata, business records, and deployment status only when the user enables those surfaces.

The toolkit does not intentionally collect, store, or return passwords, tokens, private keys, OAuth codes, cookies, payment credentials, or other secret values. Secret values remain in the connected credential interface or encrypted provider storage. MCP responses contain the request text supplied to the router, capability metadata, approval classification, and evidence-based runtime status; they do not contain fabricated connector state or contact details.

No personal data is sold. Data retention and deletion follow the connected provider and the user's repository or workspace policies. Users can remove repository artifacts and revoke connected service access at any time.

Contact and policy updates are handled through the `Ogenicchocolate21debug/Build-Platform` repository support channel.
