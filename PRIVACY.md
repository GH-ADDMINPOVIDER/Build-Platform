# Privacy Policy

Developer System-Bootstrap Ops processes only the data needed to complete a user-requested workflow. It may read file metadata, repository content, workflow configuration, product/media records, and deployment status from services the user connects.

The toolkit does not intentionally store or return passwords, tokens, private keys, OAuth codes, cookies, or other secret values. Secret values remain in the connected credential interface, Infisical, or encrypted provider storage. Logs and tool responses should contain only minimal status, counts, stable resource identifiers, and recoverable errors.

No personal data is sold. Data retention and deletion follow the connected provider and the user's repository or workspace policies. Users can remove repository artifacts and revoke connected service access at any time.

Contact and policy updates are handled through the Build-Platform repository support channel.
